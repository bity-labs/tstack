## What is TStack?

TStack provides practical tooling for agentic software delivery. The first layer is a generic **engineering harness**: plain files that you add to a repository so coding agents have consistent instructions, project context, engineering doctrine, ADR guidance, and reusable workflows.

The monorepo also contains the **Agent-Ready Boilerplate** in `apps/boilerplate`: a Next.js SaaS starter that dogfoods the harness and includes authentication, billing, email, content, file upload, analytics, web3 wallet sign-in, and stack-specific agent docs.

## What the harness gives you

- `AGENTS.md` for repository-level agent instructions.
- `docs/context.md` for durable product and domain language.
- `docs/coding-standards.md` for project-specific implementation expectations.
- `docs/adr/` for architectural decisions.
- `docs/engineering/` for reusable engineering guidance.
- `.agents/skills/` for repeatable agent workflows such as ideation, PRD writing, TDD implementation, debugging, refactoring, architecture inspection, issue breakdown, and code review.

## Not included yet

TStack does not currently ship a CLI installer, automated scaffold/export command, deployment automation, repository access automation, or release automation. The boilerplate app exists in the monorepo source, but standalone app generation is still manual until an installer/scaffold is added.
