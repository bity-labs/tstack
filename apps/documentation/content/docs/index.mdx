TStack brings together reusable setup for a brain/vault, engineering harness, assistant, server, and product boilerplate. Components are intended to work independently, with optional integration. Personal data, secrets, and live runtime state stay outside the source repository.

## Current status

V2 is a workspace shell, not a completed product setup.

| Component | Status |
| --- | --- |
| Engineering harness | Existing generic instructions, skills, and doctrine |
| TStack documentation | Existing Fumadocs app |
| CLI | Retained; v2 scaffolding is not implemented yet |
| Brain | README placeholder for vault setup and skills |
| Assistant | README placeholder for Hermes-based coordination setup |
| OS | README placeholder for server setup |
| Boilerplate | README placeholders for website, application, and product documentation |

The source uses one pnpm/Turborepo workspace. The planned boilerplate export is a separate product workspace containing three independently deployable apps; the exporter is not implemented yet.
