## What is TStack?

TStack provides a generic **engineering harness** for agentic software delivery. The harness is a set of plain files that you add to an existing repository so coding agents have consistent instructions, project context, engineering doctrine, ADR guidance, and reusable workflows.

The first supported product surface is the standalone harness stored at `packages/harness/templates/default`.

## What the harness gives you

- `AGENTS.md` for repository-level agent instructions.
- `docs/context.md` for durable product and domain language.
- `docs/coding-standards.md` for project-specific implementation expectations.
- `docs/adr/` for architectural decisions.
- `docs/engineering/` for reusable engineering guidance.
- `.agents/skills/` for repeatable agent workflows such as ideation, PRD writing, TDD implementation, debugging, refactoring, architecture inspection, issue breakdown, and code review.
