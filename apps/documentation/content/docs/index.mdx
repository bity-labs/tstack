## What is TStack?

TStack is a practical stack for agent-ready software delivery. It has two usable layers today:

- **Engineering Harness** — reusable agent instructions, engineering doctrine, skills, ADR guidance, and project context files.
- **TStack Agent-Ready Boilerplate** — a Next.js SaaS starter in `apps/boilerplate` with authentication, payments, content, email, analytics, file upload, testing, web3 wallet sign-in, and boilerplate-specific agent docs.

The repository also contains this buyer-facing documentation app.

## Start here

- Use [Getting Started](/getting-started) to run the boilerplate from the monorepo or install the Engineering Harness in an existing project.
- Use [Boilerplate Overview](/boilerplate/overview) to understand the SaaS starter.
- Use [Environment Variables](/getting-started/environment-variables) before running auth, billing, email, analytics, or upload flows.
- Use [Known Limitations](/reference/known-limitations) to understand what is manual today.

## What is not included yet

TStack does not currently ship a CLI installer, scaffold command, export command, payment automation, deployment automation, or repository-access automation. The boilerplate is usable from the current monorepo source, and standalone extraction is manual until a dedicated scaffold/export command exists.
