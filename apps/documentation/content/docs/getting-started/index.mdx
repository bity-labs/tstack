## Choose your path

### Run the TStack Agent-Ready Boilerplate

Use this path when you want the full SaaS starter from `apps/boilerplate`: Next.js, Better Auth, Polar, Prisma/PostgreSQL, Resend, content, analytics, file upload, web3 sign-in, tests, and agent-facing docs.

Start with [Prerequisites](/getting-started/prerequisites), then [Quick Start](/getting-started/quick-start).

### Install the Engineering Harness only

Use this path when you already have a project and want agent instructions, reusable skills, ADRs, coding standards, and engineering doctrine.

Use the [Harness Installation](/harness/installation) guide.

## Create a standalone app

To create a standalone boilerplate app outside the monorepo, use `pnpm tstack init` from the TStack repository. It scaffolds a new app from `apps/boilerplate`, copies harness resources as real files, generates a local `.env`, and optionally initializes git and installs dependencies.

For projects that need full control over the extraction process, manual standalone extraction remains documented. See [Manual Standalone Extraction](/getting-started/manual-standalone-extraction).
