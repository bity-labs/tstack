---
title: "Repository Setup"
description: "Install dependencies and run TStack's documentation app from the current checkout."
---

From the root of the checkout containing the v2 shell:

```sh
pnpm install --frozen-lockfile
pnpm dev:documentation
```

Open the local URL printed by the development server.

## Validate the workspace

```sh
pnpm test
pnpm typecheck
pnpm lint
pnpm build
```

Turbo runs scripts for implemented packages. The README-only placeholders are not runnable workspaces. Documentation test/lint scripts currently report that no checks are configured; its typecheck and build validate the app.

## Inspect the CLI

```sh
pnpm tstack --help
```

V2 scaffolding is not implemented yet. `tstack init` reports this and does not create an app. No database or product environment setup is required for the shell.

To adopt the existing generic harness, follow [harness installation](/harness/installation). For the previous application starter, see the [preserved v1 documentation](https://github.com/bity-labs/tstack/tree/v1/apps/documentation/content/docs).
