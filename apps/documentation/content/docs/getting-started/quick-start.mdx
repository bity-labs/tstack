## Create and run a standalone app

```sh
# Clone the TStack repository
git clone https://github.com/bity-labs/tstack tstack
cd tstack

# Install dependencies
pnpm install

# Scaffold a new standalone app
pnpm tstack init my-app

# Enter your new app
cd ../my-app

# Start the database
pnpm db:start
pnpm db:push

# Run the app
pnpm dev
```

Open `http://localhost:3000`.

## What these commands do

| Command | Purpose |
| --- | --- |
| `pnpm install` | Installs TStack repository dependencies. |
| `pnpm tstack init my-app` | Scaffolds a new standalone app from `apps/boilerplate`. |
| `pnpm db:start` | Starts the local PostgreSQL Docker service. |
| `pnpm db:push` | Pushes the Prisma schema to the local database. |
| `pnpm dev` | Starts Velite and the Next.js development server. |

## Run from the monorepo instead

To run the boilerplate directly from the TStack monorepo without creating a standalone app:

```sh
git clone https://github.com/bity-labs/tstack my-app
cd my-app
pnpm install
cp apps/boilerplate/.env.example apps/boilerplate/.env
pnpm --filter @tstack/boilerplate db:start
pnpm --filter @tstack/boilerplate db:push
pnpm --filter @tstack/boilerplate dev
```
