---
title: "Environment Variables"
description: "Configure the TStack Agent-Ready Boilerplate from the current .env.example file."
---

Copy the example file before running locally:

```sh
cp apps/boilerplate/.env.example apps/boilerplate/.env
```

For a manually extracted standalone app, copy `.env.example` to `.env` from the standalone app root.

## Project URL and branding

| Variable | Purpose | Example |
| --- | --- | --- |
| `PROJECT_URL` | Server-side canonical URL used by auth and SIWE domain logic. | `http://localhost:3000` |
| `NEXT_PUBLIC_SITE_URL` | Public site URL fallback for client-visible metadata and links. | `http://localhost:3000` |
| `NEXT_PUBLIC_APP_NAME` | Display name used by UI and metadata. | `MyApp` |
| `LANDING_MODE` | Redirects most routes to `/landing` when set to `true`. | `false` |

## Polar payments

| Variable | Purpose |
| --- | --- |
| `POLAR_ACCESS_TOKEN` | Polar SDK access token for runtime billing flows. Required scopes: `checkouts:write`, `customers:read`, `customers:write`, `orders:read`, `events:read`, `events:write`, `customer_sessions:write`, `customer_portal:read`, `customer_portal:write`. |
| `POLAR_SERVER` | `sandbox` for testing or `production` for live payments. |
| `POLAR_WEBHOOK_SECRET` | Secret used by the Polar webhook plugin. Webhook receiving does not require `webhooks:*` token scopes. |
| `POLAR_ORGANIZATION_ID` | Organization identifier used by Polar-related flows that need it. |

The current app does not need `benefits:*` for benefit display because it reads customer-owned benefits/downloadables through Customer Portal APIs and customer state. It also does not need `meters:*` unless future Polar meter sync is implemented; runtime usage records/lists events and reads active meter balances from customer state. Add optional `customer_meters:read` only if you explicitly build against Better Auth usage customer-meter endpoints.

| `EMAIL_BRAND_LOGO_URL` | Optional logo URL used by email templates. |

## Analytics

| Variable | Purpose |
| --- | --- |
| `NEXT_PUBLIC_ANALYTICS_PROVIDER` | `umami`, `posthog`, or `none`. |
| `NEXT_PUBLIC_UMAMI_WEBSITE_ID` | Umami website ID. |
| `NEXT_PUBLIC_UMAMI_HOST` | Umami script host, defaults to `https://cloud.umami.is`. |
| `NEXT_PUBLIC_POSTHOG_KEY` | PostHog project key. |
| `NEXT_PUBLIC_POSTHOG_HOST` | PostHog host, defaults to `https://eu.posthog.com`. |

## Upload provider

| Variable | Purpose |
| --- | --- |
| `FILE_UPLOAD_PROVIDER` | `database` for zero-config local storage or `digitalocean` for Spaces. |
| `MAX_FILE_SIZE_MB` | Maximum image upload size in megabytes. |
| `DIGITALOCEAN_SPACES_ENDPOINT` | Region endpoint only, for example `https://ams3.digitaloceanspaces.com`. |
| `DIGITALOCEAN_SPACES_REGION` | Spaces region, for example `ams3`. |
| `DIGITALOCEAN_SPACES_BUCKET` | Bucket name. |
| `DIGITALOCEAN_SPACES_ACCESS_KEY_ID` | Spaces access key. |
| `DIGITALOCEAN_SPACES_SECRET_ACCESS_KEY` | Spaces secret key. |
| `DIGITALOCEAN_SPACES_CDN` | Optional CDN URL returned for uploaded files. |
