---
title: "Prerequisites"
description: "Tools for developing the current TStack source workspace."
---

Use:

- Git and access to the TStack repository.
- Node.js 24 LTS.
- pnpm 10.28.1, as pinned in the root `package.json`.

Docker, a database, and application-provider credentials are not required to run the current documentation app or validate the shell.

The new component directories have no runtime requirements yet because they contain only README placeholders. Installing the generic harness into an existing project requires only the template files and a way to copy and merge them; see [harness installation](/harness/installation).
