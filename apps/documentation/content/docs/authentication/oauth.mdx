The boilerplate ships with GitHub and Twitter/X OAuth provider support.

## Environment variables

| Provider | Variables |
| --- | --- |
| GitHub | `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET` |
| Twitter/X | `TWITTER_CLIENT_ID`, `TWITTER_CLIENT_SECRET` |

Providers are configured in `src/lib/auth/oauth.ts` and passed to Better Auth from `src/lib/auth/config.ts`.

## Callback URLs

Use these callback URLs when creating provider apps:

| Provider | Local callback |
| --- | --- |
| GitHub | `http://localhost:3000/api/auth/callback/github` |
| Twitter/X | `http://localhost:3000/api/auth/callback/twitter` |

Replace the host with your production domain for production apps.

## Client usage

```ts
import { signIn } from "@/lib/auth-client";

await signIn.social({
  provider: "github",
  callbackURL: "/dashboard",
});
```

OAuth buttons live in `src/features/authentication/components/social-auth-buttons.tsx` and are shown only for configured providers.

## Adding a provider

1. Add env vars to `.env.example` and `src/config/env.ts`.
2. Add the provider to `src/lib/auth/oauth.ts`.
3. Add a button/icon in the social auth component.
4. Update this documentation and any tests.
