Product and meter configuration currently lives in the boilerplate source.

```txt
polar/
├── products.sandbox.json
├── products.production.json
├── products.schema.json
├── meters.sandbox.json
├── meters.production.json
└── meters.schema.json

src/features/billing/generated/
├── products.generated.ts
└── meters.generated.ts
```

## Important limitation

There is no buyer-facing TStack command for syncing products or regenerating product files today. Do not tell buyers to run a product CLI as a current TStack feature. Until a dedicated workflow exists, update the JSON and generated TypeScript deliberately and keep them in sync with the Polar dashboard.

## Product JSON shape

Each product has a stable slug, a billing type, price data, display metadata, and an environment-specific Polar product ID.

```json
{
  "slug": "pro-monthly",
  "name": "Pro Monthly",
  "description": "Full access to all features, billed monthly",
  "type": "subscription",
  "recurringInterval": "month",
  "prices": [{ "amountType": "fixed", "amount": 1900, "currency": "usd" }],
  "display": {
    "title": "Pro",
    "subtitle": "Billed monthly",
    "badge": null,
    "features": ["Unlimited projects", "Priority support"],
    "highlighted": false,
    "cta": "Get Started"
  },
  "polarProductId": "your-polar-product-id"
}
```

Production products may have `polarProductId: null` until you create live Polar products. Checkout filters out products with missing IDs.

## Generated product helpers

`src/features/billing/generated/products.generated.ts` exports helpers used by pricing UI and checkout configuration:

```ts
getProducts(env);
getDisplayProducts(env);
getCheckoutProducts(env);
```

- `getDisplayProducts` drives pricing and plan-selection UI.
- `getCheckoutProducts` passes configured products to the Better Auth Polar checkout plugin.
- Slugs are stable across environments; product IDs differ between sandbox and production.

## Meter configuration

Meters are configured similarly:

```json
{
  "slug": "llm-tokens",
  "name": "LLM Tokens",
  "polarMeterId": "your-polar-meter-id",
  "eventNames": ["use-credit"]
}
```

The generated meter helpers expose meter lookup and event display names for credit usage UI.

## Safe update checklist

- [ ] Create or update products/meters in the correct Polar environment.
- [ ] Update the matching `polar/*.json` file.
- [ ] Update generated TypeScript to match the JSON.
- [ ] Confirm pricing cards show intended customer-facing products.
- [ ] Confirm checkout only includes products with real Polar IDs.
- [ ] Test sandbox checkout before switching `POLAR_SERVER=production`.
