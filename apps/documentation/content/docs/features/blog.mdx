The boilerplate includes a sample blog powered by [Velite](https://velite.js.org/) and MDX. The shipped content is sample content meant to be replaced with your own marketing or product education content.

## Content location

```txt
content/blog/
└── hello-world.mdx
```

Each post uses frontmatter:

```mdx
---
title: "Hello World"
description: "Welcome to the blog."
date: "2026-01-01"
slug: "hello-world"
tags: ["announcement"]
draft: false
---

Write your post here.
```

## Routes

| Route | Purpose |
| --- | --- |
| `/blog` | Paginated blog index. |
| `/blog/[slug]` | Individual post page. |

Draft posts are visible in development and hidden in production.

## Implementation files

| File | Purpose |
| --- | --- |
| `velite.config.ts` | Defines the MDX collection and output. |
| `src/features/blog/` | Blog models, utilities, and rendering components. |
| `src/app/(marketing)/blog/page.tsx` | Blog index route. |
| `src/mdx-components.tsx` | MDX component mapping. |

## Replacing sample content

1. Delete or rewrite `content/blog/hello-world.mdx`.
2. Add your own posts with unique slugs.
3. Keep titles and descriptions useful for SEO.
4. Run `pnpm --filter @tstack/boilerplate typecheck` or `build` so Velite validates the content.
