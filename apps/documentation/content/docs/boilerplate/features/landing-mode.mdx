---
title: "Landing Mode"
description: "Use the built-in pre-launch landing page and newsletter capture."
---

Landing mode redirects most requests to `/landing` so you can collect emails while building the full product.

## Enable it

Set the environment variable:

```sh
LANDING_MODE=true
```

Run the app:

```sh
pnpm --filter @tstack/boilerplate dev
```

Visit any protected or marketing route and it should redirect to `/landing`.

## What stays public

In landing mode, middleware allows only these routes by default:

```ts
const LANDING_MODE_ALLOWED_ROUTES = [
  routes.landing,
  routes.legal.termsOfService,
  routes.legal.privacy,
];
```

## Newsletter capture

Newsletter code lives in `src/features/newsletter`:

```txt
src/features/newsletter/
├── actions/newsletter.action.ts
├── components/newsletter-form.tsx
├── schemas/newsletter.schema.ts
└── services/newsletter.service.ts
```

The default action saves collected emails to the database. The service also contains a provider path for Resend contacts if you choose to enable it.

## Customize the landing page

- Page route: `src/app/(landing)/landing/page.tsx`.
- Client component: `src/app/(landing)/landing/client-page.tsx`.
- Copy: `src/locales/index.ts` under the landing/newsletter sections.
- Styling/components: `src/components` and `src/components/ui`.

Disable landing mode by setting `LANDING_MODE=false`.
