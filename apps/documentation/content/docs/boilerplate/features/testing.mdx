The boilerplate uses Vitest, React Testing Library, Happy DOM, and Prisma mocks.

## Commands

Run from the TStack monorepo root:

```sh
pnpm --filter @tstack/boilerplate test
pnpm --filter @tstack/boilerplate test:watch
pnpm --filter @tstack/boilerplate test:coverage
```

For a manually extracted standalone app, run the equivalent package scripts from that app root:

```sh
pnpm test
pnpm test:watch
pnpm test:coverage
```

## File conventions

Tests are colocated with source files and use `.test.ts` or `.test.tsx`.

```txt
src/lib/errors.ts
src/lib/errors.test.ts
src/components/ui/badge.tsx
src/components/ui/badge.test.tsx
```

## Test setup

| File | Purpose |
| --- | --- |
| `vitest.config.mts` | Test environment, aliases, setup files, coverage. |
| `src/test/setup.ts` | Global mocks for Next.js navigation and headers. |
| `src/test/prisma-mock.ts` | Prisma mock singleton reset between tests. |

## What to test

- Server utilities through public wrappers.
- Auth, billing, upload, and email boundaries with provider mocks.
- Feature behavior through exported public APIs.
- UI primitives and forms with React Testing Library.

Prefer behavior tests over implementation-detail tests.
