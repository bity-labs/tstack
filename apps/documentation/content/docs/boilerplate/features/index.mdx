The TStack Agent-Ready Boilerplate ships with production-oriented defaults that are meant to be customized for your product.

| Feature | What it gives you |
| --- | --- |
| [Landing Mode](/boilerplate/features/landing-mode) | Pre-launch page and newsletter capture. |
| [Blog / MDX Content](/boilerplate/features/blog) | Sample Velite-powered blog content for marketing and SEO. |
| [Server Utilities](/boilerplate/features/server-utilities) | Unified query/action/route wrappers with auth and errors. |
| [Error Handling](/boilerplate/features/error-handling) | Typed errors, consistent responses, and app error boundary. |
| [Emails](/boilerplate/features/emails) | Resend + React Email templates through a typed dispatcher. |
| [Analytics](/boilerplate/features/analytics) | Umami/PostHog provider switch and tracking wrapper. |
| [File Upload](/boilerplate/features/file-upload) | Database uploads for local use and DigitalOcean Spaces for production. |
| [Testing](/boilerplate/features/testing) | Vitest, React Testing Library, and Prisma mocks. |
