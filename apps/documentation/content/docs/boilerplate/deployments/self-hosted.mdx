This recipe is for deploying the boilerplate to a server managed by Coolify or a similar self-hosted platform.

## Prerequisites

- A server with Coolify installed.
- A PostgreSQL database reachable from the app.
- A domain pointing at the server.
- Production values for Better Auth, database, Polar, email, analytics, and uploads.

## Monorepo deployment commands

When deploying directly from the current TStack monorepo, use filtered workspace commands:

| Setting | Value |
| --- | --- |
| Install command | `pnpm install --frozen-lockfile` |
| Build command | `pnpm --filter @tstack/boilerplate build` |
| Start command | `pnpm --filter @tstack/boilerplate start` |
| Port | `3000` |

Run migrations before or during deploy:

```sh
pnpm --filter @tstack/boilerplate db:migrate
```

A common start command for simple platforms is:

```sh
pnpm --filter @tstack/boilerplate db:migrate && pnpm --filter @tstack/boilerplate start
```

For stricter production setups, run migrations as a separate release step rather than on every process start.

## Standalone deployment commands

If you manually extracted a standalone app, commands usually become:

| Setting | Value |
| --- | --- |
| Build command | `pnpm build` |
| Start command | `pnpm start` |
| Migration command | `pnpm db:migrate` |

Make sure standalone extraction copied `.agents` and `docs/engineering` as real files for agent work, but they do not affect runtime deployment.

## Environment variables

At minimum, set:

```sh
PROJECT_URL=https://myapp.example.com
NEXT_PUBLIC_SITE_URL=https://myapp.example.com
NEXT_PUBLIC_APP_NAME=MyApp
BETTER_AUTH_SECRET=...
BETTER_AUTH_URL=https://myapp.example.com
DATABASE_URL=postgresql://...
POLAR_ACCESS_TOKEN=...
POLAR_SERVER=production
POLAR_WEBHOOK_SECRET=...
RESEND_API_KEY=...
RESEND_SEGMENT_ID= # optional newsletter/landing segment
EMAIL_FROM_ADDRESS=no-reply@myapp.example.com
SUPPORT_EMAIL=support@myapp.example.com
```

Add OAuth, wallet, analytics, and upload provider variables based on the features you enable.

## Coolify outline

1. Create a Coolify project.
2. Add a PostgreSQL database resource or connect an external database.
3. Add an application from your Git repository.
4. Configure the build/start commands above.
5. Add environment variables.
6. Deploy.
7. Add the custom domain and enable HTTPS.
8. Configure Polar webhook URL after the domain is live.

## Troubleshooting

- Build failure: confirm the app is using pnpm and the build command targets `@tstack/boilerplate` when deploying the monorepo.
- Database failure: confirm `DATABASE_URL` is reachable from the app container.
- Auth callback failure: confirm `BETTER_AUTH_URL`, provider callback URLs, and `PROJECT_URL` use the deployed domain.
- Payment sync failure: confirm `POLAR_SERVER`, token, webhook secret, and webhook URL all target the same Polar environment.
