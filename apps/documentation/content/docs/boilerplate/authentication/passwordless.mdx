title: "Passwordless / Email OTP"
description: "Sign in with a one-time code sent by email."
---

The boilerplate includes the Better Auth Email OTP plugin. Users can sign in or sign up by entering an email address, receiving a six-digit code, and verifying it.

## Key files

| File | Purpose |
| --- | --- |
| `src/lib/auth/plugins/email-otp.ts` | Server plugin configuration. |
| `src/lib/auth.constants.ts` | OTP length, expiry, and max attempts. |
| `src/lib/auth-client.ts` | Email OTP client plugin. |
| `src/features/authentication/components/otp-verification.tsx` | OTP input UI. |
| `src/features/authentication/hooks/use-auth-form.ts` | Sends and verifies codes. |
| `src/components/emails/OtpEmail.tsx` | OTP email template. |

## Flow

1. User enters an email without a password on login or signup.
2. The app sends an OTP through `authClient.emailOtp.sendVerificationOtp()`.
3. User enters the code in the OTP input.
4. The app calls `signIn.emailOtp()`.
5. Better Auth signs in the existing user or creates a new account.

## Security defaults

- Six-digit codes.
- Five-minute expiry.
- Limited verification attempts.
- Additional rate limits on send and verify endpoints.

## Production notes

Passwordless auth depends on email delivery. Configure Resend and test the full flow before relying on it in production.
