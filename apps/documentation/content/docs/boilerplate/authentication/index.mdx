title: "Authentication Overview"
description: "Better Auth flows included in the TStack Agent-Ready Boilerplate."
---

The boilerplate uses Better Auth for application authentication. It ships with multiple flows so builders can remove what they do not need:

- Email/password signup and login with email verification.
- Password reset and change-password support.
- Email OTP passwordless sign-in.
- GitHub and Twitter/X OAuth.
- SIWE wallet sign-in through RainbowKit, Wagmi, and viem.
- Account deletion with confirmation email.
- Database-backed rate limiting for sensitive auth endpoints.

## Key files

| File | Purpose |
| --- | --- |
| `src/lib/auth/config.ts` | Better Auth server configuration. |
| `src/lib/auth/oauth.ts` | OAuth provider configuration. |
| `src/lib/auth/rate-limit.ts` | Rate-limit settings. |
| `src/lib/auth/plugins/` | Email OTP, Polar, and SIWE plugin wiring. |
| `src/lib/auth/email-hooks.ts` | Email callbacks delegated to `sendEmail`. |
| `src/lib/auth/user-hooks.ts` | Change-email and delete-user hooks. |
| `src/lib/auth-client.ts` | Client auth helpers and plugins. |
| `src/features/authentication/` | Auth forms, hooks, schemas, social buttons, and SIWE button. |
| `src/middleware.ts` | Route protection and access gating. |

## Public auth routes

| Route | Purpose |
| --- | --- |
| `/login` | Sign in with email/password, OTP, OAuth, or wallet. |
| `/signup` | Create an account. |
| `/forgot-password` | Request a password reset link. |
| `/reset-password` | Set a new password from a reset token. |

## Production setup checklist

- [ ] Set `BETTER_AUTH_SECRET` to a strong secret.
- [ ] Set `BETTER_AUTH_URL` and `PROJECT_URL` to the production domain.
- [ ] Configure only the OAuth providers you will show.
- [ ] Configure Resend before relying on email verification or password reset in production.
- [ ] Configure Polar if paid access depends on checkout/customer state.
- [ ] Test route protection after changing public or paid routes.
