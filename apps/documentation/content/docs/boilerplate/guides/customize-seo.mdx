---
title: "Customize SEO"
description: "Set global metadata, page metadata, Open Graph assets, and sitemap behavior."
---

## 1. Update global metadata

Edit `src/locales/index.ts`:

```ts
export const locales = {
  metadata: {
    title: "MyApp",
    description: "Describe your product clearly.",
  },
};
```

## 2. Use page metadata helpers

Pages should compose metadata with helpers from `src/lib/metadata.ts`:

```ts
import { createMetadata, getDefaultMetadata } from "@/lib/metadata";
import { locales } from "@/locales";

export const metadata = createMetadata({
  ...getDefaultMetadata(),
  title: locales.HomePage.metadata.title,
  description: locales.HomePage.metadata.description,
});
```

## 3. Replace Open Graph image

The app includes `src/app/opengraph-image.png`. Replace it with a 1200x630 image that matches your product branding.

## 4. Replace favicons and manifest assets

Update files under `public/`, including favicon, touch icon, and manifest assets.

## 5. Configure canonical URLs

Set production URL variables:

```sh
PROJECT_URL=https://myapp.example.com
NEXT_PUBLIC_SITE_URL=https://myapp.example.com
BETTER_AUTH_URL=https://myapp.example.com
```

## 6. Validate

Build the app and inspect generated metadata, sitemap, and social preview cards:

```sh
pnpm --filter @tstack/boilerplate build
```
