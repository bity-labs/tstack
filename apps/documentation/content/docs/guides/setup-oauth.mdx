---
title: "Set Up OAuth"
description: "Configure GitHub or Twitter/X login."
---

## GitHub

1. Open GitHub Developer Settings.
2. Create a new OAuth app.
3. Use `http://localhost:3000` as the local homepage URL.
4. Use `http://localhost:3000/api/auth/callback/github` as the local callback URL.
5. Copy the client ID and secret.

Add them to `apps/boilerplate/.env`:

```sh
GITHUB_CLIENT_ID=...
GITHUB_CLIENT_SECRET=...
```

## Twitter/X

1. Open the Twitter/X Developer Portal.
2. Create an app with OAuth 2.0 enabled.
3. Use `http://localhost:3000/api/auth/callback/twitter` as the local redirect URI.
4. Copy the client ID and secret.

```sh
TWITTER_CLIENT_ID=...
TWITTER_CLIENT_SECRET=...
```

## Production callbacks

Create separate production provider apps or add production callbacks:

```txt
https://yourdomain.com/api/auth/callback/github
https://yourdomain.com/api/auth/callback/twitter
```

## Test

1. Run `pnpm --filter @tstack/boilerplate dev`.
2. Open `/login` or `/signup`.
3. Click the provider button.
4. Complete provider authorization.
5. Confirm you return signed in.
