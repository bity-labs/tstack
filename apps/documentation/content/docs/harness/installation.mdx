---

## Prerequisites

You need:

- A target project repository.
- A TStack checkout or package source that contains `packages/harness/templates/default`.
- A shell that can copy files.

## Copy the default template

The installable template is:

```txt
packages/harness/templates/default
```

Copy its contents into the root of your target project:

```sh
SOURCE=/path/to/tstack/packages/harness/templates/default
TARGET=/path/to/your/project
cp -R "$SOURCE"/. "$TARGET"/
```

This adds the harness files directly to the target project root.

## Merge existing project files carefully

If your project already has any of these paths, review them before copying:

- `AGENTS.md`
- `docs/context.md`
- `docs/coding-standards.md`
- `docs/adr/`
- `.agents/skills/`

Prefer an intentional merge so you preserve project-specific instructions and avoid replacing real context with template placeholders.

## Customize after copying

At minimum, update:

1. `docs/context.md` with real product and domain language.
2. `docs/coding-standards.md` with real validation commands and conventions.
3. `AGENTS.md` with any repository-specific navigation rules.

The copied template includes placeholder text. Do not treat placeholders as authoritative project context.

## Validate the install

Ask a coding agent to read `AGENTS.md` and summarize the project instructions it found. Then run your project's normal validation command to ensure the copy did not disturb the repository.

There is no TStack CLI installer yet, so installation is complete when the files are copied, customized, committed, and usable by your agent.
