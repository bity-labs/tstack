---
title: "Commands"
description: "Common commands for the TStack docs, harness, and boilerplate."
---

Run these from the TStack monorepo root unless noted.

## Documentation app

```sh
pnpm --filter @tstack/documentation dev
pnpm --filter @tstack/documentation typecheck
pnpm --filter @tstack/documentation build
```

## Boilerplate local development

```sh
cp apps/boilerplate/.env.example apps/boilerplate/.env
pnpm --filter @tstack/boilerplate db:start
pnpm --filter @tstack/boilerplate db:push
pnpm --filter @tstack/boilerplate dev
```

## Boilerplate validation

```sh
pnpm --filter @tstack/boilerplate lint
pnpm --filter @tstack/boilerplate typecheck
pnpm --filter @tstack/boilerplate test
pnpm --filter @tstack/boilerplate build
```

## Boilerplate database

```sh
pnpm --filter @tstack/boilerplate db:start
pnpm --filter @tstack/boilerplate db:stop
pnpm --filter @tstack/boilerplate db:push
pnpm --filter @tstack/boilerplate db:migrate
pnpm --filter @tstack/boilerplate db:studio
pnpm --filter @tstack/boilerplate db:reset
```

Use `db:push` for local iteration and `db:migrate` for applying migrations in deployed environments.

## Emails

```sh
pnpm --filter @tstack/boilerplate email:dev
```

This starts the React Email preview server for templates under `src/components/emails`.

## Harness template copy

```sh
SOURCE=/path/to/tstack/packages/harness/templates/default
TARGET=/path/to/your/project
cp -R "$SOURCE"/. "$TARGET"/
```

Commit copied harness files after customizing project context.

## Whole workspace validation

```sh
pnpm lint
pnpm typecheck
pnpm test
pnpm build
git diff --check
```
