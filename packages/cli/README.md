# @tstack/cli

Customer-facing TStack repository CLI for scaffolding apps and managing local billing configuration.

## Local development

Run the CLI from the package directory:

```sh
pnpm tstack <command> [options]
```

Build the package:

```sh
pnpm build
```

Run tests:

```sh
pnpm test
```

## User documentation

See the [TStack CLI guide](https://doc.tstack.dev/reference/cli) for setup and usage. Repository access is free; the CLI is built locally rather than installed from npm.
