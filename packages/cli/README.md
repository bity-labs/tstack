# @tstack/cli

Customer-facing TStack repository CLI for scaffolding apps and managing local billing configuration.

## Local development

Run the CLI from the package directory:

```sh
pnpm tstack <command> [options]
```

Build the package:

```sh
pnpm build
```

Run tests:

```sh
pnpm test
```

## Buyer-facing documentation

See the [TStack CLI guide](https://github.com/bity-labs/tstack/tree/quality/apps/documentation/content/docs/reference/cli.mdx) for buyer usage.
